Sideloading Guide

How to install BitChord on iOS.

Download the latest signed-ready .ipa from GitHub Releases and install it on your iPhone or iPad using AltStore, ESign, or SideStore.

Latest iOS IPA Release

Always download official builds directly from Karthik's GitHub Releases.

Open GitHub Releases →
1

Set up AltStore

Install AltServer on your Mac or Windows PC, connect your iPhone via USB, and install AltStore onto your device.

2

Download the IPA

Open GitHub Releases in Safari on your iPhone and download the latest BitChord.ipa file to Files.

3

Import into AltStore

Open AltStore → My Apps, tap the + button in the top-left corner, and select the downloaded BitChord.ipa.

4

Sign & Refresh

Wait for AltStore to sign and install (keep AltServer running on the same Wi-Fi). Refresh once every 7 days on free Apple IDs.

1

Open ESign

Install ESign on your iPhone and import your Apple developer or enterprise signing certificate (.p12 + .mobileprovision).

2

Download the IPA

Grab the latest BitChord.ipa from GitHub Releases in Safari.

3

Import & Sign

In ESign, tap Import, choose BitChord.ipa, tap it under Apps, select Signature, and sign with your certificate.

4

Install On-Device

Once signing finishes, tap Install directly on your iPhone—no computer needed.

1

Install SideStore

Complete the one-time SideStore setup with pairing file and WireGuard/StosVPN enabled on your iPhone.

2

Download the IPA

Download BitChord.ipa from GitHub Releases.

3

Sideload Wirelessly

Turn on your SideStore VPN, open SideStore → My Apps → +, and select BitChord.ipa.

4

Auto-Refresh

Refresh BitChord anytime over Wi-Fi directly on your iPhone without touching a PC or Mac.

First launch tip: If iOS asks to trust the app, open Settings → General → VPN & Device Management, tap your Apple ID / certificate under Developer App, and tap Trust.
